# Windows 多点配送二维仿真

这是不连接 ROS、底盘或实车的桌面演示。使用纯 Python 标准库，地图每格代表 0.5 米；虚拟车从 H（装载点）出发，按输入顺序到 A/B/C 送货，每站等待人工确认，最后返回 H。地图中深色格为障碍，可在运行中点击增删；路径被挡时尝试重新规划，无路可走则停止并记录原因。

## 运行

在 Windows 中双击仓库根目录的 `start_delivery_sim.cmd`。也可以在仓库根目录打开 PowerShell：

```powershell
python -m delivery_sim
```

输入 `A,B,C` 或其他不重复顺序，点击“开始配送”。到站后点击“确认取货”；可以暂停、取消或在地图上点击增删障碍。“自动测试 10 次”会运行不同顺序、动态障碍和目标封堵共十个场景，把每次轨迹、路程、时间、重新规划次数及失败原因保存到 `artifacts/delivery_sim/`。默认含一个预期失败场景，因此正常结果是 9/10 成功。

核心逻辑检查：

```powershell
python -m unittest delivery_sim.test_core
```

## 验证范围

本程序验证订单顺序、到站停等、人工确认、网格寻路、改道和停止等任务流程。地图是示意图，位置、激光、里程计和运动均为软件模型；它**没有调用 Nav2，也不能证明真实小车的定位、避障或制动性能**。接入 ROS 2 时，需要用 Nav2 导航反馈替换网格移动，并单独设计配送模式的运动授权，不得直接绕过 `motion_guard`。
